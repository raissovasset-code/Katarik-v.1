# Катарик

Онлайн-карточная игра для браузера и будущего мобильного приложения.

## План проекта

Главный актуальный план разработки: [KATARIK_CHECKLIST.md](./KATARIK_CHECKLIST.md).

Ссылка на игру: https://katarik-5g25.onrender.com

## Что уже есть

- Комнаты по коду и ссылке.
- Онлайн-игра через WebSocket.
- 2-11 игроков.
- Режимы: обычный, на вылет, погоны.
- Колода 4-A, 2, 3, джокеры и ДВК.
- Раздача карт, пас, ход по часовой стрелке.
- Проверка комбинаций: одна карта, двойник, три одинаковых, четыре одинаковых, катарик, бомба.
- Отдельная компьютерная сцена.
- Начат отдельный мобильный вид через `view=mobile`.
- Серверные тесты правил.

## Локальный запуск

Открой два терминала.

Сервер:

```bash
cd server
npm install
npm run dev
```

Клиент:

```bash
cd client
npm install
npm run dev
```

Компьютерная версия:

```text
http://localhost:5173
```

Мобильный вид:

```text
http://localhost:5173/?view=mobile
```

## Проверки

Серверные тесты:

```bash
cd server
npm test
```

Сборка клиента:

```bash
cd client
npm run build
```

## Публикация в интернет

Самый простой вариант сейчас: один Render Web Service.

Почему один сервис:

- сайт и сервер будут на одном домене;
- WebSocket будет работать на том же адресе;
- телефону не нужен локальный IP компьютера;
- не нужно отдельно настраивать `VITE_WS_URL`.

В проект уже добавлены:

- `render.yaml`
- корневой `package.json`
- сервер умеет отдавать собранный клиент из `client/dist`

На Render:

1. Загрузи проект в GitHub.
2. В Render создай новый **Blueprint** или **Web Service** из этого репозитория.
3. Если Render спросит команды:

```bash
npm run build
```

```bash
npm start
```

4. После деплоя открой выданную ссылку.

Компьютерная версия:

```text
https://your-app.onrender.com
```

Мобильный вид:

```text
https://your-app.onrender.com/?view=mobile
```

Вход в комнату с телефона:

```text
https://your-app.onrender.com/?room=КОДКОМНАТЫ&view=mobile
```
