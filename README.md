# Катарик — Telegram Mini App MVP

Онлайн-карточная игра для Telegram Mini App.

## Что уже есть
- Комнаты по коду
- 2–11 игроков
- Колода 52 карты + 2 джокера + 1 ДВК
- При 2 игроках карты раздаются на 3 стопки, третья сжигается
- Раздача всех карт
- Определение игрока с 4♠ для первого кона
- WebSocket-синхронизация
- Пас
- Черновая проверка комбинаций:
  - одиночная карта
  - пара
  - сет
  - каре
  - ряд
  - двойной ряд
  - ДВК как wild card, кроме джокеров
  - 3333 как непобиваемое каре

## Запуск локально

### Сервер
```bash
cd server
npm install
npm run dev
```

### Клиент
```bash
cd client
npm install
npm run dev
```

По умолчанию клиент подключается к `ws://localhost:3001`.
